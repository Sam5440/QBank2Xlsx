# 题目解析拆分与展示列表实施计划

## 目标

将当前“题目生成”默认行为改为不生成解析，并新增独立的解析生成能力。前端在“AB 对比审核”上方增加完整题目展示列表，让用户能直观看到每道题的题干、题型、选项、答案、章节、难度和解析状态，并支持单题生成解析与一键生成全部缺失解析。

## 现状判断

- 默认系统提示词在 `src/qbank2xlsx/config.py` 中要求“如果原始材料中没有解析，你必须为每个题目生成详细的解析说明”。
- 前端默认生成提示词在 `web/static/app.js` 里也包含同样的解析要求。
- 当前生成结果主要以 `可编辑 JSON`、`完整输出` 和 `AB 对比审核` 内的文件 A/B 文本框展示，缺少按题目维度的可读列表。
- 导出 Excel、Word、JSON 的数据源是 AB 对比审核中的文件 A，因此解析生成后需要同步回文件 A 和对应输出 JSON。

## 实施方案

### 1. 调整题目生成提示词

- 修改 `DEFAULT_SYSTEM_PROMPT`：
  - 默认要求 `解析（勿删）` 输出为 `null`。
  - 只有当原始材料明确包含解析，或用户需求明确要求生成解析时，才填写解析字段。
  - 保持 JSON 顶层结构、字段名和选项 A-H 规则不变。
- 修改前端 `DEFAULT_PROMPTS.generation`，保持与后端默认提示词一致。
- 修改 AB 对比提示词：
  - 默认不再把“缺少解析”视为问题。
  - 仅在原始需求明确要求解析，或文件 A 已有解析但内容错误时审核解析质量。

### 2. 新增解析生成提示词

- 增加默认解析提示词，例如 `QUESTION_EXPLANATION_PROMPT`：
  - 输入：单道题的完整 JSON、题目上下文、可选原始需求。
  - 输出：只返回 JSON，形如 `{"analysis": "解析内容"}`。
  - 约束：不得修改题干、选项、题型、答案、章节、难度；解析必须基于题目和正确答案，不编造无关知识。
- 在前端提示词编辑器中新增“解析生成提示词”入口，允许用户自定义。

### 3. 新增后端解析接口

- 在 `src/qbank2xlsx/ai_service.py` 增加解析生成函数：
  - 单题非流式：`generate_question_explanation(...)`
  - 如需批量更稳定，可复用现有后台任务模式，增加批量任务状态。
- 在 `app.py` 增加请求模型和接口：
  - `POST /api/generate-explanation`：单题生成解析。
  - 视确认结果决定是否同时加 `POST /api/generate-explanations-batch/start` 和进度轮询接口。
- AI 调用调试记录新增 kind，例如 `explanation`，方便在现有调试日志里排查。

### 4. 新增题目展示列表

- 在 `web/index.html` 的 `result-section` 与 `compare-section` 之间插入 `question-preview-section`。
- 在 `web/static/app.js` 中增加派生数据函数：
  - 从所有 `editable-*` JSON 合并题目。
  - 从 `fileA` 读取题目。
  - 保留每道题来源：输出编号、题目序号、原始数组索引。
- 列表展示字段：
  - 序号、题型、难度、章节、题干、选项、正确答案、解析状态。
  - 解析为空显示“待生成”，已有解析显示解析文本。
- 顶部操作：
  - 一键生成解析。
  - 仅显示缺解析题。
  - 刷新列表。
  - 同步到文件 A。
- 单题操作：
  - 生成解析。
  - 重新生成解析。
  - 展开或收起解析。

### 5. 解析生成后的数据同步

- 单题解析成功后，更新内存中的题目对象。
- 同步写回：
  - 对应 `editable-*` JSON。
  - AB 对比审核的 `fileA`。
  - 题目展示列表状态。
- 导出 Excel、Word、JSON 继续复用现有 `getFileAQuestions()`，这样解析生成后可直接导出。

### 6. 错误处理与交互状态

- 单题和一键解析都显示状态：待生成、生成中、已生成、失败。
- 一键解析只处理缺失解析的题目，已有解析默认跳过。
- API 配置缺失、文件 A 为空、JSON 无效时沿用现有 error/log 机制。
- 解析生成失败不影响题目本身和导出功能。

### 7. 验证清单

- 批量生成题目后，默认 `解析（勿删）` 为 `null`。
- 原始需求明确要求解析时，生成提示词允许写入解析。
- 题目展示列表能从多段输出正确合并所有题目。
- 单题生成解析后，对应 JSON 与文件 A 均被更新。
- 一键解析只补全缺失解析，不覆盖已有解析。
- AB 对比不再默认因缺少解析扣分。
- Excel、Word、JSON 导出能带上后来生成的解析。

## 需要你确认的点

- 一键解析是否默认覆盖已有解析：建议默认不覆盖，只补空。
- 解析生成是否需要流式显示：建议单题非流式，一键批量显示进度即可。
- 展示列表是否默认从 `fileA` 读取：建议优先 `fileA`，没有文件 A 时从各输出 JSON 派生。
